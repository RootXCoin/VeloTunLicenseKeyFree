## 📌 What is VeloTun?

**VeloTun** is a lightweight, high-performance **OpenVPN management panel** built for anyone who needs to run and manage VPN servers without deep Linux or networking expertise. Whether you're an individual self-hosting a personal VPN, a small business securing remote access, or a VPN provider managing multiple servers and customers, VeloTun gives you a clean **web-based dashboard** to control everything — user creation, expiration, bandwidth limits, protocols, and multi-server orchestration — from one place.

If you're searching for a **free OpenVPN admin panel**, **OpenVPN user management tool**, or **self-hosted VPN control panel**, VeloTun is designed to be a fast, no-fuss alternative to manual `.ovpn` file management and command-line server administration.

## 🔑 How to Activate Your License

1. In your VeloTun panel, go to **Admin → License**
2. Paste your license key into the field
3. Click **Activate** (or **Reactivate** if updating an existing key)
4. Confirm the status shows **Pro**, along with your plan and connection limit
